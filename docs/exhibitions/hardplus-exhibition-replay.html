Load the Hard+ exhibition into the app replay

This page only converts the recorded exhibition artifact into one archived replay entry for the app. It changes nothing else, and it never plays a move itself. For the standalone board viewer with its own controls, use replay.html.

How to watch it

  1. Serve the repository root over http so this page and the app share one origin (localStorage is per-origin), e.g. python3 -m http.server 8081 from the repository root, or npm run exhibition:replay.
  2. Open this page at http://localhost:8081/docs/exhibitions/hardplus-exhibition-replay.html and press Load into existing replay.
  3. Open the app at ../../index.html, then go to Replays and pick the Hard+ vs Pinned Hard entry. The app's own replay screen supplies the back/forward controls, the step slider and the board rendering — this page adds no playback UI of its own.

The entry is written to the app's normal replay archive (ww_replay_hist) as a local 9x9 duel. Existing entries are kept; only a previously loaded copy of this exhibition is replaced, and the archive stays capped at the app's ten most recent entries.
